# Code of Conduct

Sci-Map follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, critique records and evidence rather than people, and assume good faith. Challenging a verdict is a normal and welcome contribution; doing it with insults is not.

Report unacceptable behavior privately to the maintainer through GitHub (user RanchoTao), or by opening a confidential security advisory if the matter is sensitive. Reports are handled confidentially.
