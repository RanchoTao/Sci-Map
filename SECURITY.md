# Security policy

Report vulnerabilities privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository. Please don't open a public issue.

In scope: the local server (`serve.py`), the static site, the private-catalog import path, CI workflows (including repro execution), and any way private ledger data could leak into the public build.

If a published record contains credentials, personal data or material that shouldn't be public, report it the same way and it will be removed from the current tree; note that git history may need separate cleanup.
